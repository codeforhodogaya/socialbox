## 📂 STACUL構造ファイル群（for AI）

このリポジトリの `/docs/stacul/` ディレクトリには、マルチAI対応フレームワーク「AI OF STACUL+」に関するコアファイルを格納しています。

| ファイル名 | 内容 |
|------------|------|
| `stacul_system_minimal.yaml` | 極限軽量SYSTEMプロンプト。ChatGPT・Claude・Gemini完全対応。 |
| `stacul_plus_extreme_prompt.txt` | 人間がAIに入力するための命令テンプレート。 |
| `fivebooks_reference.yaml` | 意味づけ支援用の五書（聖書・御書・孫子等）参照辞書。 |
| `stacul_usecase.md` | STACULを実践適用した事例記録集。フレーム別・五書対応付き。 |

これらはAIモデルによる参照に最適化されており、RAWファイルリンクを通じて直接読み込みも可能です。
