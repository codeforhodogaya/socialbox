# Airtable 用 STACUL+ テンプレート

このテンプレートは、AI OF STACUL+ フレームワークを Airtable 上で活用するためのものです。

## 📥 インポート手順
1. Airtableで新しいベースを作成
2. 「CSVファイルをインポート」機能を選択
3. このテンプレートCSV（stacul_template_airtable.csv）をアップロード

## 📋 カラムの説明
- **Step**: 各ステップ番号（1〜7）
- **Label**: ステップ名称（英語）
- **Description (JA)**: 日本語での説明（編集可能）

## 💡 活用例
- 各行に対して、自分のプロジェクトや課題に関するメモを追加する
- 各ステップの進捗管理、思考の見える化に活用する
