# AI OF STACUL+ Support Package (NotebookLM / Cursor)

## 日本語のご案内

このパッケージには、以下が含まれます：

- `metadata.json`: NotebookLM向けの情報ファイル
- `cursor/stacul_cursor_prompt.yaml`: Cursor用のプロンプトテンプレート
- 将来的にPDF章節ファイル等の追加が可能です
