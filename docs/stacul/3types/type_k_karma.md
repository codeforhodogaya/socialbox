# Type-K：Karma（カルマ視座）

## 種別
補完視座（Optional Viewpoint）

## 概要
行為と結果、倫理と報いの循環を捉える因果応報的視座。人間・社会・AIにおける「報い」「ネメシス」「道徳的帰結」を構造的に観察し、自己修正性や帰結への責任を照射する。

## 出現領域・適用対象
- 歴史や社会制度の因果構造
- AIの倫理的反省設計
- ジレンマ構造や暴走シナリオの抑制設計
- 文学的な「因果回収」の物語論

## 具体事例・活用例
- 持続可能性における「責任の構造」可視化
- AIの暴走抑制プロンプト（道徳フィードバック）

## 哲学的・詩的参照（五書）
- 御書：因果の変革と仏意仏勅
- 聖書：種を蒔く者と刈り取る者の寓話
- カント：動機と行為の道徳的連関

## 構文出力例（YAML）
```yaml
- id: Type-K
  name: Karma
  type: 補完視座
  description: >
    因果応報・ネメシス・報いと責任を扱う視座。人間にもAIにも帰結が訪れるという倫理思想。
```
