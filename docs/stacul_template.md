# YAMLテンプレート構文解説（STACUL+）

このテンプレートは、AI OF STACUL+ の11視座に基づき、各項目ごとに記述ガイドを付したYAML構文です。

## 各項目の概要

- **O（OODA）**：観察・意味づけ・決定・行動の4段階を記述
- **I（IKIGAI）**：好き・得意・必要・報酬の4つの観点からモチベーションを整理
- **B（BMC）**：ビジネスモデルキャンバスの9要素を簡略に適用
- **T（TOC）**：制約条件を特定し、集中資源投下による突破口を設計
- **U（U理論）**：未来に共鳴し、変容のプロセスを描く
- **S（SCQA）**：物語構造（状況→複雑性→問い→答え）で構成
- **P（PESTLE）**：外部環境のマクロ要素（政治・経済・技術等）を分析
- **C（Culture）**：ブルデューの文化資本理論（3分類）で人と環境を読み解く
- **D（Dialogue）**：対話や協働を設計する視点
- **L（Liberal Arts）**：歴史・思想・芸術からの視座・暗示
- **W（Well-being）**：前野隆司氏による幸福の4因子を用いた評価軸

## 使用方法

このテンプレートは、AI対話プロンプト、政策設計、事業企画、教育・研修等のフレームとして活用できます。
