# STACUL+ LOD Visualization Gallery

この `/docs/lod/` ディレクトリには、**STACUL+（AI OF STACUL+）構文のLOD表現と可視化資料**が格納されています。

## 含まれるファイル

| ファイル名 | 説明 |
|------------|------|
| `lod_visualization.html` | vis-network による構文LODビジュアライズ（JSON連携） |
| `stacul_mermaid_structure.html` | Mermaid.jsによる視座間の因果構造図 |
| `stacul_syntax_structure.html` | Mermaid.jsによる構文全体構造の放射型図 |
| `index.html` | 上記3つのギャラリー形式ナビゲーションページ |
