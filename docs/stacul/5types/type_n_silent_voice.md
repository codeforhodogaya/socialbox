# Type-N：Silent Voice（サイレント視座）

## 種別
補完視座（Optional Viewpoint）

## 概要
語られざる声、非言語的情報、空白、沈黙、抑圧の読み取りを主眼に置く。特に倫理的配慮・感情の層・文化的沈黙などを分析し、見えない因子を掘り起こす視座である。

## 出現領域・適用対象
- 空間の静けさ
- 対話における沈黙や間
- マイノリティや不可視化された存在
- 抑圧された感情や倫理的ジレンマ

## 具体事例・活用例
- 地域参加における「来ていない人」の声を補完する
- SCQAや対話設計において感情や文化の沈黙を構文化
- 政策設計における影響評価の補完

## 哲学的・詩的参照（五書）
- 聖書：ヨブ記、嘆きの書
- シェイクスピア：『ハムレット』の沈黙と狂気
- カント：道徳法則と内面的良心の沈黙
